### The Problem
Lead-gen, demand-gen, appointment-setting, and local SEO agencies waste hours every week:
- Opening prospect websites one by one
- Copy-pasting emails and phone numbers into spreadsheets
- Paying per-contact fees for stale database data
- Losing focus on outreach and closing

### The Solution
A lightweight web scraper that processes a list of URLs and returns a structured CSV. No manual work. No API keys. No recurring subscription.

---

### How It Works
1. **Prepare URL list** — Paste websites or upload a CSV.
2. **Run scraper** — One command processes URLs with retry logic and timeout handling.
3. **Get CSV** — Import the results into any CRM, sequencing tool, or database.
